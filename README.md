# dsh-superagent-playground
Playground repo watched by dsh-superagent

## Install

This repository has no build step or dependencies. To use it, clone it with Git:

```sh
git clone https://github.com/SS-LAU/dsh-superagent-playground.git
cd dsh-superagent-playground
```

Then open `README.md` in your editor or viewer of choice.
